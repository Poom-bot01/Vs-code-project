# Lamoon API v1

เว็บไซต์ลูกค้าและหน้า Admin ใช้ JSON API ชุดเดียวกัน หน้าเว็บยังให้บริการจาก `server.py` ส่วนแอปในอนาคตสามารถเรียก HTTP API นี้ได้โดยตรง ไม่ต้องเขียนกฎคำนวณราคาและจัดการสถานะซ้ำ

## เริ่มระบบ

```sh
python3 server.py
```

เว็บลูกค้า: `http://localhost:8000/order_food.html`  
หน้า Admin: `http://localhost:8000/admin.html`  
API base: `http://localhost:8000/api/v1`

## Endpoints

| Method | Path | หน้าที่ |
| --- | --- | --- |
| GET | `/api/v1/health` | ตรวจสอบว่า API พร้อมทำงาน |
| GET | `/api/v1/menu` | รายการอาหารและราคาปัจจุบัน |
| POST | `/api/v1/orders` | สร้างออเดอร์ |
| GET | `/api/v1/orders` | ดูออเดอร์สำหรับหน้า Admin |
| GET | `/api/v1/orders/{id}` | ติดตามสถานะออเดอร์รายรายการ |
| PATCH | `/api/v1/orders/{id}` | เปลี่ยนสถานะเป็น `ready` เมื่ออาหารเสร็จ |
| DELETE | `/api/v1/orders/{id}` | ลบออเดอร์ |

ตัวอย่างสร้างออเดอร์:

```json
{
  "name": "คุณสมชาย",
  "items": [
    { "menuId": 1, "qty": 2 },
    { "menuId": 7, "qty": 1 }
  ]
}
```

เซิร์ฟเวอร์รับออเดอร์เข้าครัวให้อัตโนมัติ โดยเริ่มสถานะเป็น `preparing` และคำนวณราคา/ยอดรวมจากเมนูฝั่งระบบ เมื่ออาหารเสร็จ Admin เปลี่ยนเป็น `ready` ได้ จากนั้น API ตอบกลับออเดอร์ในรูปแบบ JSON ที่มี `id`, `name`, `items`, `total`, `createdAt` และ `status` ข้อผิดพลาดตอบเป็น `{ "error": "..." }` ทุก endpoint ใช้ JSON และ API รองรับ CORS สำหรับ client ที่ทำงานคนละ origin

## โครงสร้าง

- `server.py` รับ HTTP request, ให้บริการหน้าเว็บ และ route API
- `lamoon/catalog.py` เป็นแหล่งข้อมูลเมนูร่วมของทุก client
- `lamoon/orders.py` มีกฎสร้าง/เปลี่ยน/ลบออเดอร์ ไม่ผูกกับหน้าเว็บ
- `lamoon/repository.py` จัดเก็บข้อมูลออเดอร์ ปัจจุบันใช้ JSON; เปลี่ยนเป็นฐานข้อมูลภายหลังได้โดยคง API เดิม
- `lamoon/reset_scheduler.py` ตั้งเวลาล้างออเดอร์ทุก 30 วันและเก็บกำหนดรอบไว้ใน `data_reset_schedule.json`
- `order_food.html` และ `admin.html` เป็นเว็บ client ของ API v1

ตัวจัดเวลาจะเริ่มนับ 30 วันเมื่อเปิดใช้งานครั้งแรก และจะรีเซ็ตเฉพาะออเดอร์ใน `orders.json` โดยไม่ลบเมนูหรือข้อมูลกำหนดรอบ หากเซิร์ฟเวอร์ปิดตอนถึงกำหนด จะทำการรีเซ็ตเมื่อเปิดเซิร์ฟเวอร์ครั้งถัดไป

API ยังไม่กำหนดระบบล็อกอินตามที่ต้องการ หน้าดูและจัดการออเดอร์จึงเปิดให้ผู้ที่เข้าถึงเซิร์ฟเวอร์ได้ใช้งาน
